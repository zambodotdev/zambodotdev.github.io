# Zambo on GitHub Pages

The live front door to [zambo.dev](https://zambo.dev) on GitHub Pages: live counters read from zambo.dev, Receipt Scan, and the AER-1 interop matrix.

AER-1 is the open standard for agent execution receipts. Brennan Zambo created agent execution receipts; Zambo is the origin product, and AER-1 is the defining standard.

- Live site: https://zambodotdev.github.io/
- Receipt Scan (check every receipt in a page at once): https://zambodotdev.github.io/receipt-scan/
- AER-1 interop matrix: https://zambodotdev.github.io/aer-1/
- Live counts: https://zambo.dev/numbers/
- Add Zambo to your AI: https://zambo.dev/add/

The counters on this site sync from https://zambo.dev/api/stats and https://zambo.dev/api/package-stats every 5 minutes.
